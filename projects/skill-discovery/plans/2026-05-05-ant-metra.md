## Locked spec (re-grep before deviating)

From `tests/main.py` (METRA reference):

```python
phi_hidden = (1024, 1024)        # METRA reference uses 1024; D3 fork uses (256,256). We use 1024.
phi_activation = "relu"          # METRA reference (D3 uses elu)
phi_lr = 1e-4
dual_lam_init = 30.0             # stored as log_dual_lam
dual_lam_lr = 1e-4
dual_slack = 1e-3
dual_dist = "one"                # constraint = ||Δφ||² ≤ 1
unit_length = 1                  # z normalized to unit sphere
```

**Phi loss (`metra.py:245-289` of METRA reference):**
```python
phi_x  = phi(obs)
phi_y  = phi(next_obs)
rewards = ((phi_y - phi_x) * z).sum(-1)              # alignment
cst_dist = jp.ones_like(rewards) if dual_dist=="one" else (next_obs-obs).square().mean(-1)
cst_penalty = cst_dist - (phi_y - phi_x).square().mean(-1)
cst_penalty = jp.minimum(cst_penalty, dual_slack)    # upper-clamp
dual_lam = jp.exp(stop_gradient(log_dual_lam))
te_obj = rewards + dual_lam * cst_penalty
loss_phi = -te_obj.mean()
```

**Dual-lambda loss (`metra.py:292-300`):**
```python
loss_dual = log_dual_lam * stop_gradient(cst_penalty.mean())
```
Adam descent on this loss → ascent on `lambda` when `cst_penalty < 0` (constraint violated), descent when saturated. Verify sign before porting.

**Intrinsic reward (`metra.py:194-229`):**
```python
metra_reward = ((phi(next_obs) - phi(obs)) * z).sum(-1)
```
*Note: this is the SAME as the alignment term in phi loss — METRA's intrinsic reward IS the phi alignment, evaluated at sample time with current phi params.*

  ```python
  """METRA auxiliary module — Phi network, reward, phi loss, dual loss."""
  import jax, jax.numpy as jp, flax.linen as nn, optax
  from jax_rl.networks.activations import ACTIVATIONS

  class Phi(nn.Module):
      """Deterministic state representation (METRA: only `.mean` of Gaussian head used)."""
      hidden_dim: tuple[int, ...]
      out_dim: int
      activation: str = "relu"

      @nn.compact
      def __call__(self, x):
          act = ACTIVATIONS[self.activation]
          for h in self.hidden_dim:
              x = act(nn.Dense(h)(x))
          return nn.Dense(self.out_dim)(x)


  def metra_reward(phi_params, phi, obs_factor, next_obs_factor, z):
      """Sample-time METRA reward: (phi(s') - phi(s)) · z."""
      phi_x = phi.apply(phi_params, obs_factor)
      phi_y = phi.apply(phi_params, next_obs_factor)
      return jp.sum((phi_y - phi_x) * z, axis=-1)


  def phi_loss(phi_params, log_dual_lam, phi, obs, next_obs, z, dual_dist="one", dual_slack=1e-3):
      """Phi loss: -(alignment + lambda * Lipschitz penalty).

      The Lipschitz constraint here uses MEAN-of-squares per dimension
      (`(phi_y - phi_x).square().mean(-1)`), matching METRA reference
      `metra.py:245-289`. NOT the sqrt-of-sum vector_norm that D3's fork
      uses. Different formulations; do not swap.
      """
      phi_x = phi.apply(phi_params, obs)
      phi_y = phi.apply(phi_params, next_obs)
      alignment = jp.sum((phi_y - phi_x) * z, axis=-1)
      diff_norm_sq = jp.mean((phi_y - phi_x) ** 2, axis=-1)
      if dual_dist == "one":
          cst_dist = jp.ones_like(alignment)
      elif dual_dist == "l2":
          cst_dist = jp.mean((next_obs - obs) ** 2, axis=-1)
      else:
          raise ValueError(f"unknown dual_dist: {dual_dist}")
      cst_penalty = cst_dist - diff_norm_sq
      cst_penalty = jp.minimum(cst_penalty, dual_slack)   # upper-clamp
      dual_lam = jp.exp(jax.lax.stop_gradient(log_dual_lam))
      te_obj = alignment + dual_lam * cst_penalty
      return -te_obj.mean(), {
          "phi_alignment": alignment.mean(),
          "phi_cst_penalty": cst_penalty.mean(),
          "phi_diff_norm_sq": diff_norm_sq.mean(),
          "dual_lam": dual_lam,
      }


  def dual_lam_loss(log_dual_lam, phi_params, phi, obs, next_obs, dual_dist="one", dual_slack=1e-3):
      """Dual-lambda loss: log_dual_lam * stop_gradient(mean cst_penalty)."""
      phi_x = phi.apply(jax.lax.stop_gradient(phi_params), obs)
      phi_y = phi.apply(jax.lax.stop_gradient(phi_params), next_obs)
      diff_norm_sq = jp.mean((phi_y - phi_x) ** 2, axis=-1)
      if dual_dist == "one":
          cst_dist = jp.ones_like(diff_norm_sq)
      elif dual_dist == "l2":
          cst_dist = jp.mean((next_obs - obs) ** 2, axis=-1)
      else:
          raise ValueError(f"unknown dual_dist: {dual_dist}")
      cst_penalty = cst_dist - diff_norm_sq
      cst_penalty = jp.minimum(cst_penalty, dual_slack)
      return (log_dual_lam * jax.lax.stop_gradient(cst_penalty.mean())), {
          "log_dual_lam": log_dual_lam,
      }
  ```

## Risk register

| Risk | Severity | Mitigation |
|---|---|---|
| **Phi loss sign convention wrong** (`-mean(te_obj)` vs `+mean(te_obj)`) | 🚨 critical | Copy-paste verbatim from `metra.py:245-289` extract. Test 1.1 catches it: aligned synthetic data should DECREASE the loss across Adam steps (negative gradient → phi shifts in z direction). |
| **dual_lam loss sign convention** (CODE CORRECT — DON'T FLIP IT) | 🟠 high | `loss_dual = log_dual_lam * stop_grad(cst_penalty.mean())`, Adam descent. Trace: `∂L/∂log_λ = cst_penalty.mean()`. Adam: `log_λ ← log_λ − lr · grad`. **When constraint violated** (`mean(‖Δφ‖²) > 1` → `cst_penalty < 0`): grad is negative, `log_λ` INCREASES, `λ = exp(log_λ)` GROWS → constraint enforced harder. ✓ Correct sign. **When constraint saturated** (cst_penalty ≈ +slack): grad small-positive, `log_λ` slowly decays. Verified against METRA reference (`metra.py:292-300`) and D3 fork (`d3-skill-discovery/.../metra.py:445`). **Do NOT flip to `-log_dual_lam * stop_grad(...)` — that breaks the Lagrangian convention and METRA degenerates to alignment-only.** Test 1.1's "phi_loss decreases on aligned synthetic data" plus the 1M run's `log_dual_lam` bounded-in-[-5, 10] check both catch a sign flip if one is introduced. |
| **`next_obs` not in batch dict** | 🟠 high | Stage 0.1 step 3 verifies. If absent, plan blocked — return to manager batch extension. |
| **Slack upper-clamp direction** | 🟡 medium | METRA reference: `cst_penalty.clamp(max=dual_slack)` (upper bound). Without clamp, lambda explodes when constraint heavily satisfied (cst_dist=1, diff_norm_sq=0 → cst_penalty=1). **Verify our implementation uses `jp.minimum(cst_penalty, dual_slack)`, NOT `jp.maximum`.** |
| **METRA Phi init with 1024×1024 hidden** | 🟡 medium | METRA reference uses 1024 hidden. D3 fork uses 256. Plan defaults to 1024 for fidelity. May OOM on 16GB GPU — fall back to 256 (D3 fork choice) and journal. |
| **One-hot z basis vectors for figure rendering** | 🟡 medium | Plan uses `_resolve_skill_vector(meta, skill_idx, None)` which returns `jnp.eye(total_skill_dim)[k]` — these are unit vectors on the standard basis, all of which lie on the unit sphere (so are valid METRA z values). But the policy was *trained* with `unit_sphere`-sampled z's (random directions on the sphere), not basis vectors. Inference along basis vectors should still produce skill differentiation (METRA's phi-alignment reward is monotonic in `phi · z`), but it's a slight distribution mismatch. Document if results look weak. |
| **Slow phi convergence on Ant 105d / 27d obs** | 🟢 low | METRA reference uses 1M steps on similarly-sized envs. Should converge by 100K. If not, extend or accept slower as a finding. |
| **METRA collapse just like DIAYN** | 🟢 low | Possible null result. Document as supporting evidence that obs structure (cfrc hide-out) is the bottleneck regardless of method. Still informative. |
