# 2026-03-29 — MuJoCo Warp Go2 Environment

## What happened

Built the Go2 Warp environment end-to-end. Trains on unitree_mujoco's exact go2.xml (full cylinder collision geometry) via the MuJoCo Warp backend. This eliminates the sim2sim gap caused by MJX's missing cylinder-box collisions.

## Key decisions

- **New env class, not modifying existing MJX env** — clean separation, zero risk to working MJX path. Warp is Beta in Playground.
- **Vendored unitree_mujoco's go2.xml** (NOT Menagerie's) — this is the actual deploy model. Menagerie go2.xml has different damping (2.0 vs 0.1), friction (0.6 vs 0.4), and is tuned for MJX stability rather than hardware accuracy.
- **Two contact modes** — `contact_mode="training"` (firm Go1-style contacts, proven for gaits) and `contact_mode="deploy"` (unitree-native physics, for transfer validation).
- **No actuator remapping** — policy trains from scratch on unitree's FR-first actuator order. Deploy code already handles remapping at inference time.
- **Controlled duplication** of go2_joystick.py → go2_warp_joystick.py. Will likely diverge during reward/physics tuning. Shared sensor helpers extracted to go2_sensors.py to avoid duplicating that layer.

## Research finding

Asymmetric actor-critic was invented OFF-policy (Pinto et al. 2017, DDPG), not on-policy. ICML 2025 paper proves unbiased policy gradients for any algorithm. No published system combines SAC + privileged critic + legged locomotion — added as future TODO.

## Implementation

- Vendored unitree go2.xml + 16 mesh files, patched with 4 foot sites
- Scene XML with full sensor block (4 sensors missing from unitree XML that Menagerie has)
- Go2WarpEnv base class + WarpJoystick env
- Extracted go2_sensors.py (shared between MJX and Warp)
- Parameterized domain randomization body ID (was hardcoded to 1)
- Fixed Playground 0.2.0 API: nconmax → naconmax
- Registered as Go2WarpJoystickFlat

## Results

- **27/27 tests pass** (15 Warp + 12 MJX regression)
- **Smoke test (500k steps, 64 envs):** 8.5k sps, eval 0.6, no NaN/crash
- **Full run (50M steps, 1024 envs):** 91k sps with naccdmax=2000. In progress.

## Issue: CCD overflow

At 1024 envs, Warp's CCD buffer was too small for unitree's complex collision geometry. Produced 8.6M lines of overflow warnings, dropped sps from 91k → 65k. Fixed by setting `naccdmax=2000`. Remaining ~1430 warnings are occasional spikes. See lessons/mjx.md for details.
