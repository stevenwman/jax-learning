## Concepts reviewed (for my own notes)

- **UTD ratio in parallel envs.** Effective UTD = `grad_updates_per_step / num_envs`. The knob name is misleading — `grad_updates_per_step` is "per outer iteration," not per env transition. With `num_envs=1024, grad_updates_per_step=1`, UTD ≈ 0.001. Off-policy algos crank `grad_updates_per_step` precisely to compensate for parallel-collection dilution. UTD–sample-efficiency link is a strong tendency but not a theorem (high-UTD overfitting regimes, variance-dominance cases break the mechanical intuition).
- **Loop/algo contract.** Shared `offpolicy_loop.run_offpolicy_loop` only touches four algo entry points: `init`, `select_action`, `update`, plus an externally-built `explore_fn`. Everything algo-specific (target nets, α, twin critics, polyak) lives inside `TrainingState` and the algo module. FlashSAC breaks this contract on 4 axes (BN state, stateful Zeta noise, adaptive reward scaling, BN-aware target update) — which is why it gets its own training script.
- **Exploration separation.** `explore_fn` is separate from `algo.select_action` because (a) eval uses deterministic actions (no noise), (b) exploration schedule is a loop-level concern, (c) SAC-family exploration is implicit in policy sampling while TD3-family exploration is explicit `deterministic_action + noise`. Keeping the two separate avoids polluting `select_action` with training-time noise.

## Refactor: `jax.value_and_grad` call sites

Across the off-policy algos, gradient computation was written as:

```python
(_, metrics), grads = jax.value_and_grad(
    _loss, argnums=0, has_aux=True
)(param, other_arg, ...)
```

The `)(` pattern — close the `value_and_grad` factory call, then immediately invoke the returned function — is a speed bump every time you read it. Extracted into a named `grad_fn`:

```python
grad_fn = jax.value_and_grad(_loss, argnums=0, has_aux=True)
(_, metrics), grads = grad_fn(param, other_arg, ...)
```

Zero behavior change. Applied to sac.py (3 blocks), td3.py (2), fast_sac.py (3), fast_td3.py (2), flash_sac.py (2). Flash_sac's critic block already used a readable outer-parens style — left alone. PPO already used one-liners.
