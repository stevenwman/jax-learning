## API Page Overhaul

All 6 API reference pages were rewritten from mkdocstrings autodoc to hand-crafted Markdown:
- Summary table at top of each page
- Structured sections with import lines, constructor code blocks, field tables

Motivation: mkdocstrings produced flat unstyled paragraphs ("wall of gray text"). Hand-crafted pages are scannable in 5 seconds.

## Glossary Auto-Linking System

Built a mkdocs hook (`docs/scripts/glossary_links.py`) that:
1. Reads `docs/glossary.md` headings → builds term→anchor map
2. Reads `docs/includes/term_links.yml` → non-glossary terms (PPO→api/algos.md#ppo, etc.)
3. On each page, replaces first occurrence of each term with a subtle link
4. Skips code blocks, headings, existing links, and the target page itself
5. Uses `.gl` CSS class — inherits text color, light underline, highlights on hover

### Bugs fixed:
- "On-policy" replacement caused "Policy" to match inside the generated markdown
- Fix: collect all positions first, reject overlapping ranges, apply in reverse
- Relative paths: needed `../` prefix based on page depth
- `<abbr>` experiment attempted but removed — users expected clicks not tooltips
- `pointer-events: none` on `a abbr` didn't help; removed entire abbreviation system
