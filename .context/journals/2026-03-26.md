## W&B Dashboard Polish

Brainstormed and implemented metric grouping for the W&B dashboard. Goal: lab members can read the dashboard at a glance without knowing metric internals.

### Design decisions
- **4 collapsible sections** via slash-prefixed keys: `perf/`, `critic/`, `actor/`, `infra/`
- **Remapping centralized in `metrics_logger.py`** — train scripts unchanged except adding one `wandb_setup_metrics()` call each
- **CSV stays flat** — no prefix changes, W&B and CSV are independent
- **Superset mapping** — PPO and off-policy metrics all defined; W&B ignores keys that never get logged
- **`define_metric(summary=...)` guarded** with try/except for older wandb versions
- **No `step_metric`** — eval dicts don't contain `total_steps` key, would conflict. The `step=` arg to `wandb.log()` handles x-axis.
- **Videos scrapped** — adds EGL rendering latency to training loop, not worth it now

### Files changed
- `jax_rl/training/metrics_logger.py` — `_WANDB_PREFIX` dict, `wandb_setup_metrics()`, updated `wandb_log()` to remap
- `train_offpolicy.py`, `train_ppo_fast.py`, `train_ppo.py` — import + one-line `wandb_setup_metrics()` call
- `tests/test_wandb_metrics.py` — 6 unit tests for remapping logic
