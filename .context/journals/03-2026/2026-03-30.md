# 2026-03-30 — Manipulation Environments (PandaPickCube SAC)

## What happened

Surveyed manipulation benchmark landscape (ManiSkill, MJLabs, MuJoCo Playground, RoboCasa, etc.) and discovered Playground already ships 10 manipulation tasks. Trained SAC on PandaPickCube — first 2M steps insufficient (approach only), extended to 10M steps which achieved successful cube picking.

## Key decisions

- **MuJoCo Playground over ManiSkill** — zero integration cost (already installed, JAX-native). ManiSkill is PyTorch/PhysX, would need DLPack bridge.
- **SAC over PPO for manipulation** — manipulation tasks have short episodes (150 steps), sparse-ish staged rewards, and benefit from off-policy sample efficiency.
- **10M steps, not 2M** — 2M steps only learned approach phase (gripper→box). The staged reward structure (box_target gated behind `reached_box` flag) requires enough exploration to discover the full grasp-lift sequence.

## Implementation

- Added PandaPickCube SAC preset in `env_presets.py`: episode_length=150, total_timesteps=10M, inherits _SAC_BASE_ALGO (UTD=8, batch_size=512, q_layer_norm=True).
- No code changes needed beyond the preset — env_setup.py already handles Playground registry loading, NaN safety, and wrap_for_brax_training.

## PandaPickCube env details (from Playground source)

- **Backend:** MuJoCo Warp (`impl='warp'`), not pure MJX
- **Action space:** 7 DOF delta joint position control, action_scale=0.04
- **Obs space:** ~54d flat (qpos, qvel, gripper_pos/mat, obj_pos/mat, relative positions, control error)
- **Episode length:** 150 steps (ctrl_dt=0.02, sim_dt=0.005)
- **Reward structure:** staged — gripper_box (4.0) gets gripper near box, box_target (8.0) only activates after `reached_box` flag (gripper within 1.2cm). Plus regularization: no_floor_collision (0.25), robot_target_qpos (0.3).
- **Target position:** randomly sampled at z=0.2-0.4 above initial box position (requires lifting)
