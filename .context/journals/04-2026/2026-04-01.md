## Asymmetric off-policy critic

Added `critic_obs_dim` to all 4 off-policy algos (SAC, TD3, FastSAC, FastTD3). Actor sees 48d `obs["state"]`, critic sees 122d `obs["privileged_state"]`. Auto-detected from dict obs in training loop.

Key changes:
- Algo loss functions: `_critic_loss` uses `batch["critic_obs"]` for Q, `batch["next_obs"]` for actor forward. `_actor_loss` uses `batch["obs"]` for actor, `batch["critic_obs"]` for Q evaluation.
- Buffer extended with `extra_obs_dims` to store critic obs at matching indices.
- Eval Q diagnostics pass raw env obs to `q_fn`, which extracts privileged_state.
- Fixed naming mismatch: `critic_next_obs` (algo convention) vs `next_critic_obs` (buffer convention).

**197/197 tests pass** (28 new asymmetric tests + 4 buffer extra obs tests). Smoke tested on Go2Warp with 64 envs.

## Bongo Board Handstand Environment

Built a complete Go2 bongo board handstand env — MJCF, env class, CMA-ES keyframe optimization, first training runs.

### Bongo Board MJCF
- Board (30"×8") with captive roller (4.6" main / 3.9" extension diameter)
- Roller is child body of board: slide + hinge joints coupled by no-slip equality constraint (`slide = -r × spin`)
- Constraint sign had to be flipped empirically. Tight solref/solimp — error <0.5mm.

### Handstand Keyframe (CMA-ES)
- 97° pitch handstand (NOT 180°) + 90° yaw so front feet straddle board's rocking axis
- CMA-ES: 7 params (pitch + 6 joints, left-right symmetric with hip mirrored), `base_z` solved analytically from feet position
- **Tripod cheat exploit**: head resting on ground = 3-point stable. Fixed with non-foot floor contact check at end of rollout.
- **PD settling**: initial 5cm free-fall before PD kicks in. Fixed with 100-step settle period before termination.
- Best: gen 69, score 9572.7, PD-hold stable ~8s flat ground

### Env Class
- Subclasses `Go2WarpEnv`. Dict obs: 46d state + 98d privileged.
- Rewards: inverted_orientation(10), board_level(12), com_above_support(8), height(-5), roller_centered(-3), torques, action_rate, termination
- Termination: not handstand, board tilt >30°, base too low, roller at limit, **foot on floor**
- Antagonistic pushes: robot (±0.5 m/s) + board (±0.3 m/s) velocity kicks every 200 steps
- 15 tests pass. Registered as `Go2BongoHandstand`.

### Training Results (FastSAC, 512 envs)
- **Run 1** (5M, old rewards, no floor termination): eval 70 @ 5M, still climbing
- **Run 2** (20M, tuned rewards, no floor termination): peaked eval 397 — but robot was **cheating** (balancing on ground, not board)
- **Run 3** (20M, floor termination fix): training, early returns ~30

### Key Lessons
- Foot-floor contact termination is essential — without it the robot exploits ground balance
- CMA-ES hard rejects (1e6) poison population — use soft penalties
- `base_z` should be computed from feet position, not optimized independently
- Reward hacking is real — always verify visually what the policy is actually doing
