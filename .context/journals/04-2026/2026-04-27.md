## GPU non-determinism finding

Task 1 surfaced that the plan's byte-ID `diff` gate against a baseline
loss-line file is unfit: three same-code/same-seed/same-flag CheetahRun
smokes produced mppi=164/120/36. XLA on this GPU is non-deterministic
even under `--xla_gpu_deterministic_ops=true` (matches global memory
`feedback_gpu_nondeterminism.md`).

Plan validation gate relaxed in `7416b3f` to:
- Smoke completes (exit 0, no NaN/Traceback)
- Final EVAL mppi finite, > 20
- `tests/test_tdmpc2.py` pass-list diff vs baseline empty

Test-pass-diff is the strict equivalence gate; smoke is a "doesn't blow
up" probe.

## Why this matters

The monofile carried 5 already-fixed bugs (replay storage, action_repeat
parity, truncated/terminated conflation, dropout disabled in policy/qscale
Q forwards, MPPI temperature inversion — see `.context/lessons/tdmpc2.md`).
A new reader would have had to wade through all 1138 lines to map
"which fix lives where." Sub-package: each fix lives in the file
named after its responsibility (truncation → losses.py, dropout → losses.py,
temperature → mppi.py).
