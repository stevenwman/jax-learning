- `train_pusht.py` (manipulation benchmark, full RL-from-scratch recipe with ablation data) ships in the repo and has a solid `api/pusht.md` page, but is completely invisible from the homepage feature list, tutorials index, and architecture diagram — a newcomer browsing tutorials will never find it.
- `TerrainCurriculumDRWrapper` is the runtime engine behind all curriculum envs but is absent from `api/wrappers.md`; the class in `jax_rl/envs/wrappers/terrain_curriculum_dr.py:21` has no public API page.

- The `api/envs.md` environment table (`docs/api/envs.md:5-9`) omits `WarpJoystickCurriculum` from its summary table even though the class is fully documented later on the same page.
- No structural staleness found: MJX Go2 is correctly labelled archived (`docs/index.md:42`, `docs/tutorials/sim2real.md:20`); `sim2sim_direct.py` still exists at `deploy/sim2sim_direct.py`.

## Missing from Site (repo ships it, site doesn't mention it)

  - Site state: `api/pusht.md` is reachable via the API nav (`mkdocs.yml:111`) but is never linked from `docs/tutorials/index.md`, `docs/index.md` Key Features, or `docs/reference/architecture.md`. Search for `pusht` in all docs outside `api/pusht.md` returns zero results.
  - Recommendation: Add a "Train PushT" tutorial entry in `docs/tutorials/index.md` linking to a new `tutorials/train-pusht.md`, and add a bullet in `docs/index.md` Key Features for the manipulation benchmark.

- **[high] `train_pusht.py` missing from architecture diagram and CLI reference**
  - Repo evidence: `train_pusht.py` exists at root; standalone training loop, not `run_offpolicy_loop`.
  - Site state: `docs/reference/architecture.md:10` TRAIN node lists `train_ppo_fast.py`, `train_{sac,td3,...}`, `train_flashsac.py` — `train_pusht.py` absent. `docs/reference/cli-flags.md` is autogenerated from `docs/scripts/gen_cli_reference.py`; that script has no `train_pusht` parser (confirmed: grep returns no results).

- **[med] `TerrainCurriculumDRWrapper` undocumented in wrappers API**

  - Site state: `docs/api/wrappers.md` — no mention. Grep of all docs returns zero results.
  - Recommendation: Add a `TerrainCurriculumDRWrapper` section to `docs/api/wrappers.md` covering constructor, episode reset / curriculum advancement logic, and the wandb metric keys.

- **[low] `WarpJoystickCurriculum` missing from the environments summary table**

## Suggested Top-3 Site Additions

**1. `docs/tutorials/train-pusht.md` — PushT RL-from-scratch tutorial**
Scope: Step-by-step guide analogous to `tutorials/train-locomotion.md`. Show `train_pusht.py` quickstart command, explain `contact_gated` reward and `TimeLimit` gotcha (already documented in `api/pusht.md` but not surfaced as a tutorial), link to the ablation table. Can pull from the "Working Recipe" section of `api/pusht.md` — this is mostly reorganization, not new writing. Add to `mkdocs.yml` tutorials nav and `tutorials/index.md`. Effort: **S** (content mostly exists in `api/pusht.md`).

**2. `TerrainCurriculumDRWrapper` section in `docs/api/wrappers.md`**
Scope: Document the class constructor, the per-env spawn/reset/advancement logic, and the wandb metric keys emitted (`terrain/{type}/mean_level`, etc.). The curriculum env section in `api/envs.md` references this wrapper implicitly but the wrapper itself has no API page. A newcomer trying to extend curriculum training needs this. Effort: **S** (class is ~250 LOC with clear docstrings; `api/envs.md:94-136` already describes the advancement logic to paraphrase).

**3. `train_pusht.py` in `gen_cli_reference.py` → `docs/reference/cli-flags.md`**
Scope: Add a `build_pusht_parser()` function mirroring the argparse setup in `train_pusht.py` and call it from `gen_cli_reference.py`. The flags (`--reward-mode`, `--obs-type`, `--frame-stack`, `--coverage-shape`, `--coverage-eps`, `--success-threshold`) are unique to PushT and not discoverable from the existing CLI reference. Effort: **S** (mechanical — mirror what's done for `train_fast_sac.py`).
