# ObsSpec Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract `_get_obs()` from an 80-line inline hstack into a config-driven list of observation terms, grouped by "state" (policy) and "privileged_state" (critic). Adding a DIAYN skill vector or vision pixels = one line, not env surgery.

**Architecture:** `ObsTerm` dataclass holds `(name, fn, noise_scale)`. `ObsGroup` holds `(name, terms)`. `compute_obs(groups, noise_level, rng, **kwargs)` iterates groups, computes terms, applies noise where specified, hstacks per group. Returns `dict[str, jax.Array]` — same shape as current `_get_obs()`. Privileged group can reference the "state" group output directly.

**Tech Stack:** Python dataclasses, JAX

**Key constraint:** Zero behavior change. Same obs values, same dims, same noise. Pure refactor.

---

## Design

### ObsTerm

```python
@dataclass
class ObsTerm:
    name: str
    fn: Callable[..., jax.Array]    # (**kwargs) -> array (any shape)
    noise_scale: float = 0.0        # 0.0 = no noise (clean/privileged)
```

### ObsGroup

```python
@dataclass
class ObsGroup:
    name: str                       # "state" or "privileged_state"
    terms: list[ObsTerm]
```

### compute_obs

```python
def compute_obs(
    groups: dict[str, ObsGroup],
    noise_level: float,
    rng: jax.Array,
    **kwargs,
) -> tuple[dict[str, jax.Array], jax.Array]:
    """Compute all obs groups, apply noise, return dict + updated rng.
    
    Returns:
        (obs_dict, new_rng) — obs_dict has same keys as current _get_obs().
        new_rng must be written back to info["rng"].
    """
```

The noise application uses the same pattern as current code: `uniform(-1, 1) * noise_level * term.noise_scale`. Each noisy term consumes one RNG split.

### Privileged state includes policy state

The privileged group's first term is a special `IncludeGroup("state")` that injects the already-computed policy state vector. This preserves the current behavior where `privileged_state[:48] == state`.

```python
@dataclass
class IncludeGroup:
    """Special term that includes another group's output."""
    group_name: str
```

### How DIAYN uses this

```python
# Append skill vector to policy obs
env._obs_groups["state"].terms.append(
    ObsTerm("skill_z", lambda info, **kw: info["skill_z"])
)
```

One line. Policy obs goes from 48d to 48+z_dim. No env surgery.

import jax

    groups = {
        "state": [
            ObsTerm("x", lambda **kw: jnp.zeros(4), noise_scale=1.0),

        return data * 2

    groups = {"state": [ObsTerm("x", needs_data)]}

    obs, _ = compute_obs(groups, noise_level=0.0, rng=rng, data=jnp.array([5.0]))

        "privileged_state": [

            ObsTerm("extra", lambda **kw: jnp.array([3.0])),

    obs, _ = compute_obs(groups, noise_level=0.0, rng=rng)
    assert obs["state"].shape == (2,)
    assert obs["privileged_state"].shape == (3,)

        "other": [ObsTerm("b", lambda **kw: jnp.zeros(3))],

    obs, _ = compute_obs(groups, noise_level=0.0, rng=rng)
    assert "state" in obs

    """Each noisy term should consume an RNG split."""
    groups = {
        "state": [
            ObsTerm("a", lambda **kw: jnp.zeros(2), noise_scale=1.0),
            ObsTerm("b", lambda **kw: jnp.zeros(2), noise_scale=1.0),

- [ ] **Step 2: Implement ObsSpec**

```python
# jax_rl/envs/obs_spec.py
"""Composable observation specification.

Obs terms are functions that receive kwargs (data, info, etc.) and return
an array. Terms are grouped into "state" (policy obs) and "privileged_state"
(critic obs). Each term has an optional noise_scale.

compute_obs() iterates groups, evaluates terms, applies noise, and hstacks
per group. Returns the same dict structure as _get_obs().

For DIAYN: append ObsTerm("skill_z", lambda info, **kw: info["skill_z"])
to the "state" group. One line, no env surgery.
"""
from __future__ import annotations
from dataclasses import dataclass
from typing import Any, Callable

import jax
import jax.numpy as jp


@dataclass
class ObsTerm:
    """A single observation component."""
    name: str
    fn: Callable[..., Any]       # (**kwargs) -> jax.Array
    noise_scale: float = 0.0    # 0.0 = no noise


@dataclass
class IncludeGroup:
    """Include another group's computed output (e.g., privileged includes state)."""
    group_name: str


def compute_obs(
    groups: dict[str, list[ObsTerm | IncludeGroup]],
    noise_level: float,
    rng: jax.Array,
    **kwargs,
) -> tuple[dict[str, jax.Array], jax.Array]:
    """Compute all obs groups with noise.

    Groups are processed in dict insertion order. IncludeGroup references
    a previously computed group's output.

    Args:
        groups: Dict of {group_name: [ObsTerm | IncludeGroup, ...]}.
        noise_level: Global noise multiplier (0.0 = no noise).
        rng: JAX PRNG key. Advanced for each noisy term.
        **kwargs: Passed to each term's fn (data, info, etc.)

    Returns:
        (obs_dict, new_rng) — obs_dict maps group names to hstacked arrays.
    """
    computed = {}

    for group_name, terms in groups.items():
        parts = []
        for term in terms:
            if isinstance(term, IncludeGroup):
                parts.append(computed[term.group_name])
            else:
                val = term.fn(**kwargs)
                if term.noise_scale > 0.0 and noise_level > 0.0:
                    rng, noise_rng = jax.random.split(rng)
                    noise = (2 * jax.random.uniform(noise_rng, shape=val.shape) - 1) \
                            * noise_level * term.noise_scale
                    val = val + noise
                parts.append(val)

        computed[group_name] = jp.concatenate(parts) if parts else jp.array([])

    return computed, rng
```

- [ ] **Step 2: Replace `_get_obs()` body**

```python
def _get_obs(self, data, info):
    obs, info["rng"] = compute_obs(
        self._obs_groups,
        noise_level=self._config.noise_config.level,
        rng=info["rng"],
        data=data, info=info,
    )
    return obs
```

**IMPORTANT:** The noise RNG must be written back to `info["rng"]` — same as the current code does with `info["rng"], *noise_rngs = jax.random.split(info["rng"], 6)`.

The current `_get_obs` computes noise on raw values and THEN subtracts `_default_pose` from joint angles. In the spec, we combine these: the term fn returns `data.qpos[7:] - self._default_pose` and noise is applied to that result. This is mathematically equivalent since noise is additive.
