# API Reference

Complete reference for all public classes and configuration dataclasses. Each page documents fields, defaults, and usage patterns.

- [**Algorithms**](algos.md) — Eight self-contained RL algorithms (PPO, PPOContraction, SAC, TD3, FastSAC, FastTD3, FlashSAC, TDMPC2)
- [**Environments**](envs.md) — MuJoCo Warp locomotion environments for Unitree Go2
- [**Configs**](configs.md) — Dataclass configs for training, algorithms, and network architecture
- [**Buffers**](buffers.md) — Replay buffers for on-policy and off-policy algorithms
- [**Wrappers**](wrappers.md) — Observation transforms, action delays, domain randomization, and vectorization
- [**Networks**](networks.md) — Modular Flax encoders, policy heads, and Q-network builders
